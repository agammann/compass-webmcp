# About Compass

Compass is a free, local-first personal knowledge workspace for people who want an agent to help with notes, tasks, bookmarks, and snippets without granting broad, invisible access to an entire workspace.

Spaces organize durable records. A Context Pack selects whole Spaces or individual items for one job. The person controls WebMCP, read access, write access, and each item type through visible switches. Agent actions appear in a local activity trail, and supported writes can be undone.

Compass is not a hosted data service, remote MCP server, or account platform. It requires no API key. Workspace content stays in IndexedDB for the current browser origin.
